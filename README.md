## 📊 About Personal Journal Manager
Personal Journal Manager ek terminal-based menu-driven Python project hai jise file handling, timestamps aur string search patterns ko manage karne ke liye banaya gaya hai.

It helps users manage data through:
🧩 File System Storage (Persistent Writing/Reading)
🐍 Python Standard Libraries (Datetime integration)
🔢 Dynamic text searching mechanics
💻 Interactive command-line environment

## 💻 Terminal Usage Guide (How It Works)

| Choice | Operation | Inputs Required | Expected System Action |
| :---: | :--- | :--- | :--- |
| **1** | **📝 Add Entry** | Journal Text | Appends a fresh text block tagged with the current dynamic timestamp. |
| **2** | **📖 View Entries** | None | Reads the entire target stream file and outputs records cleanly. |
| **3** | **🔍 Search Entry** | Keyword | Iterates through line arrays to fetch specific chronological matches. |
| **4** | **🗑️ Delete All** | None | Truncates the text file target completely to wipe active records. |
| **5** | **🛑 Exit App** | None | Terminates active execution loops securely with a departure note. |
